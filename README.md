# Overview

As a software engineer, I am expanding my toolkit by learning C++, a powerful systems-level language that gives direct control over how programs run and use memory. To build a solid foundation, I started where every programmer starts: a "Hello World" program that lets me set up my environment, write code, compile it, and run it from end to end.

This software is a simple C++ console program that prints "Hello World" to the screen. It confirms that my compiler and editor are configured correctly and gives me a first look at the basic structure of a C++ program: including a header, defining the `main` function, and writing output to the console.

My purpose in writing this software was to get comfortable with the C++ workflow (writing, compiling, and running code) so I can build on it with more advanced programs in the future.

[Software Demo Video](https://youtu.be/Ea7S39OYKuI)

# Development Environment

I developed this software using Visual Studio Code as my code editor, with the Microsoft C++ compiler (MSVC) to build and run the program from the terminal. I used Git and GitHub for version control and to host the project.

The program is written in C++, using the standard library's `iostream` header for console output.
